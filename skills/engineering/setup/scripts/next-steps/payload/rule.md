# Next steps: show without being asked

End every turn that finishes a piece of work, or stops to wait for
the user, with the `fwd:next-steps` block. "Finished" means: a change
made, a run done, a PR opened, a review back. Also when the user asks
"en nu?", "wat nu?" or "wat is de status?".

Skip it for a plain question-and-answer turn, a quick back-and-forth
that has no next step, and autonomous /loop ticks.

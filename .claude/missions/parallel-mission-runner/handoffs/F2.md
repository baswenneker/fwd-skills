# F2 — fwd:mission-plan proposes the dependency DAG + DAG stats at handoff

Extended fwd:mission-plan's Step 3 to instruct the planner to propose a depends_on array per feature, with the verbatim conservative default ("when unsure, add the edge"), constraints (no forward-milestone refs, no cycles), and an annotated tree presentation format. Updated Step 7 (the handoff section) to compute and print DAG width (max wave size / largest antichain) and critical-path length, plus both run commands: /fwd:mission-run (serial, safe default) and /fwd:mission-run-parallel (parallel waves, opt-in). Added a "Feature depends_on — the dependency DAG" section to REFERENCE.md with the schema rules, the unsure→edge default, a four-feature DAG example with wave breakdown, and a cross-reference to the canonical schema doc in fwd:mission-run/REFERENCE.md. No scripts were touched; F3 (validate-artifacts.sh) remains separate.

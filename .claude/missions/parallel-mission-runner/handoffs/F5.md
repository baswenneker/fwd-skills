# F5 — pick-wave.sh + setup-slot.sh

Implemented pick-wave.sh and setup-slot.sh for the fwd:mission-run-parallel skill. pick-wave.sh reads state.json, refuses v1 missions (no depends_on key anywhere, exit 2 with /fwd:mission-run pointer), warns on chain-shaped DAGs, computes effective deps (chain semantics for an absent depends_on key in a v2 state = implicit dep on predecessor), finds the current milestone (first non-done feature), identifies ready features, and forms a wave capped at FWD_MISSION_MAX_PARALLEL respecting serial_only solo semantics; emits closes_milestone when the wave covers the milestone's full remainder. setup-slot.sh provisions or reuses .trees/mission/<slug>--slot-<n>, detaches the slot before `git branch -f` (a branch checked out in a worktree cannot be force-moved), resets tracked dirty files clean while preserving untracked artifacts (node_modules etc.), copies .env* from the main checkout root, and fails loudly if .env would not be gitignored in the slot. Both scripts follow serial-script conventions: set -euo pipefail, cwd-independent, rtk git, bash+jq only. 12 fixture self-checks in /tmp passed, plus a read-only run of pick-wave.sh against this real mission.

## Issues discovered

- macOS `git worktree list --porcelain` returns /private/tmp/... while callers use /tmp/... — avoided path normalization by detaching the slot directly in the reuse path.
- `git branch -f` fails with "cannot force update the branch used by worktree" even when the branch is checked out in the slot being reused — detach HEAD in the slot BEFORE branch -f.
- Chain detection heuristic: pure chain iff features with 0 deps (≤1 root) + features with exactly 1 dep account for all features; correctly classifies this mission's own DAG as not-a-chain (F5, F6 both depend on F4).

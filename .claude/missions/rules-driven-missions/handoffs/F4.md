# F4 — Rules-inventaris

**In één oogopslag.** Een nieuw script `list-rules.sh` levert bij het laden van `fwd:mission-plan` een compacte inventaris van `.claude/rules/`: per regelbestand één regel met relatief pad, scope (uit `paths:` frontmatter of `repo-wide`) en de eerste kopregel. Als de map afwezig of leeg is, volgt een expliciete melding; het script eindigt altijd met exit 0. In `SKILL.md` is het script via een `!`-statement gekoppeld als dynamische contextstap bij sessiestart, en er is een verplichte Stap 1.0 toegevoegd: wanneer de inventaris geen regels meldt, presenteert de planner via `AskUserQuestion` een bewuste keuze — stoppen voor `/fwd:rules-audit` (aanbevolen) of expliciet doorgaan met vastlegging in `mission.md`. Stilzwijgend doorgaan is geen optie.

Het script volgt exact de conventies van de bestaande scripts in de `fwd:mission-plan/scripts/`-map: `set -euo pipefail`, `rtk git rev-parse --show-toplevel` voor repo-root-resolutie, bash + jq + system tools, geen Node. De smoke-waves-test (73 assertions) blijft groen.
